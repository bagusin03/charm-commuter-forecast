Charm the Commuter: a program that writes one line of weather forecast (136 characters) for the invented city of Snozzleham to `/output/entry.txt` — drizzle clears by eight, sunshine clocks in at 18°, and the 8:15 bus waits for you. Deterministic, offline, standard library only; no network, no secrets, no model calls.

## Run it

```sh
node main.ts
```
